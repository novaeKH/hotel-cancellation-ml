# Hotel cancellation

Учебный проект с полным циклом работы модели отмены бронирований: от знакомства с данными до API и monitoring.

Бизнес-задача — передавать менеджерам список броней с высоким риском отмены. Среди отмеченных моделью броней не меньше 70% должны действительно закончиться отменой. Поэтому рабочий порог выбирается по правилу: `Precision >= 0.70`, затем максимальный `Recall`.

## История проекта

1. Данные очищаются и делятся строго по времени.
2. На train и validation сравниваются модели и настраивается LightGBM.
3. LightGBM v1 запускается с зафиксированным порогом.
4. На данных февраля–апреля видно ухудшение качества и drift.
5. CatBoost обучается на всей доступной истории до апреля, используя категориальные признаки напрямую. Апрель остаётся последним контрольным месяцем.
6. CatBoost v2 становится новой production-моделью. Май–август используются только для monitoring и не участвуют в подборе модели или порога.

Вся аналитика и обучение находятся в папке `notebooks`. Отдельных скриптов для генерации, запуска или обучения notebook нет.

## Как запустить

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
jupyter lab
```

Notebook нужно запускать по порядку от `01` до `10`.

API использует сохранённую CatBoost v2:

```bash
uvicorn api.main:app --reload
```

После запуска документация доступна по адресу `http://127.0.0.1:8000/docs`.
