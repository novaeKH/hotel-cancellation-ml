# Hotel booking 

В данном поекте я буду реализовывать полный ML пайплайн для реализации и выката в прод модели бронирования номеров в отеле. 

Работа будет разделена на несколько этапов: `Raw data` → `Data Understanding` → `Cleaning` → `EDA` → `Feature Engineering` → `Split` → `Baseline` → `Preprocessing` → `PCA` (как ознакомление с методом) → `Model experiments` → `Tuning` → `Interpretation` → `FastAPI` → `Production simulatio`n → `Monitoring` → `Docker/финализация`.

каждый этап имеет свой ipynb.
