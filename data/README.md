# Данные

Исходный набор: [Hotel Booking Demand на Kaggle](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand).
Описание сбора данных: [Antonio, Almeida, Nunes, 2019](https://doi.org/10.1016/j.dib.2018.11.126).

CSV содержит 119 390 бронирований двух отелей. Сохранить `hotel_bookings.csv`
в `data/raw/` или передать путь через `--data-path` при запуске эксперимента.
SHA-256 использованного файла находится в `reports/evaluation/run.json`.
Исходные и промежуточные таблицы исключены из Git.
